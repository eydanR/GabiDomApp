Conexión segura

Este HTML llama a /api/chat. Esa ruta debe vivir en un servidor o función serverless, porque la clave de OpenAI nunca debe ponerse dentro del navegador.

Cuando lo subas a Vercel, Netlify o Render, se agrega una variable privada llamada OPENAI_API_KEY y el servidor se encarga de hablar con ChatGPT.
